# Моё портфолио

Это моё личное портфолио — небольшой сайт, где собраны информация обо мне и мои работы.

## Из чего состоит проект

| Файл | Для чего нужен |
|------|----------------|
| `index.html` | Главная страница сайта (структура и содержимое) |
| `style.css` | Оформление: цвета, шрифты, расположение блоков |
| `script.js` | Скрипты: интерактивность на странице |

## Как открыть сайт

### Способ 1. Прямо на компьютере

1. Скачайте репозиторий: нажмите зелёную кнопку **Code** → **Download ZIP**.
2. Распакуйте архив в любую папку.
3. Дважды щёлкните по файлу `index.html` — сайт откроется в браузере.

### Способ 2. Через клонирование (если установлен Git)

```bash
git clone https://github.com/Gloxinia1211/I-am.git
cd I-am
```

После этого откройте `index.html` в браузере.

### Способ 3. Онлайн через GitHub Pages

Если в настройках репозитория включён GitHub Pages, сайт доступен по адресу:

https://gloxinia1211.github.io/I-am/
